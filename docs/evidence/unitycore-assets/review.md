# UnityCore Assets 独立审查

这是初次交付的审查记录。后续提交前复审发现的额外边界问题及修复见 [提交前复审](../../unitycore-assets-review.md)，本文件不代替该轮结果。

日期：2026-11-09。审查者：独立只读 agent `assets_review`。主代理负责实现、Unity 执行及证据归档；审查者没有执行 Unity 或声称独立复跑测试。

多轮审查发现并修复：

- 未激活预热对象不触发 OnDestroy：增加实际销毁观察，强退显式释放。
- 调用者取消早于原生操作完成：分别跟踪消费者和原生完成，正常关闭等待排空。
- 同步完成续体释放后重新加载：按登记对象身份回收，旧 finally 不移除新登记。
- 作用域与池保留历史句柄：释放/实际销毁时解除登记，租约失效后清空值。
- 外部销毁池对象：更新活跃/闲置计数并使旧租约失效。
- Instantiate 的 Awake/OnEnable 重入关闭：创建期间持有在途所有权；强退候选同步销毁。
- 池 OnRent/OnEnable/OnDisable、父节点切换重入：操作后重检查；激活期间自毁不能发布死租约。
- 场景身份：从实际 sceneLoaded 事件获取实例，拒绝已加载路径，禁止外部并发加载同路径。
- 场景产物证据：独立校验真实 Bundle 场景路径，场景外部普通资源仍参加报告归属验证。

最终静态复审未发现剩余确定阻断。诊断快照仅保存字符串，不保留 Unity 对象；场景/池错误记录的非阻断建议也已补齐。

针对上述问题新增真实 Bundle 与可控延迟后端回归。最终测试、Player 与源码指纹以同目录机器摘要和原始证据归档为准。此审查不代表人工审查或已接入 CI。
